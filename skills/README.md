# Project Skills

Local skill references for the Trading Journal System. These are external skill guides downloaded as Markdown for offline/project-specific use.

| Skill | Source | Purpose |
| --- | --- | --- |
| `ui-ux-pro-max` | [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | UI/UX design patterns, component architecture, responsive design |
| `trade-journal` | [agiprolabs/claude-trading-skills](https://github.com/agiprolabs/claude-trading-skills) | Trading domain knowledge, journal workflows, analytics patterns |
| `frontend-design` | [anthropics/skills](https://github.com/anthropics/skills) | Frontend design guidelines from Anthropic's skill library |
| `fastapi-python` | [mindrally/skills](https://github.com/mindrally/skills) | FastAPI best practices, async patterns, API design |
| `solid-principles` | [thebushidocollective/han](https://github.com/thebushidocollective/han) | SOLID principles, clean architecture, code quality |

## Usage for AI Agents

When working on relevant parts of this project, load the matching skill:
- UI work → `skills/ui-ux-pro-max.md` + `skills/frontend-design.md`
- Backend/API work → `skills/fastapi-python.md`
- Trading logic/journal features → `skills/trade-journal.md`
- Refactoring/architecture → `skills/solid-principles.md`
